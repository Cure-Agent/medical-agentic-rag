# 실험 기록

시점 증거 문서다. **한 실험 = 한 파일이고, 끝나면 고치지 않는다.**

새 실험이 이전 결론을 뒤집으면 새 문서를 쓰고 이전 문서 맨 위에 `superseded by` 배너만
추가한다. 숫자는 그대로 둔다 — 「1회 실행이 이렇게 틀릴 수 있다」는 것 자체가 증거다.

`results/`는 gitignore이고 실행마다 덮어써지므로 **숫자는 문서 본문에 박는다.**

## 현재 판정 요약

**검색 경로는 운영 현행 유지** — 원 질문 1개 → 하이브리드 → RRF 무절단 → 리랭커 → top-5 →
점수 게이트. 제안된 세 개입이 모두 기각됐다:

| 개입 | 효과 (complex, k=5) | 판정 |
|---|---|---|
| query decomposition (변형 B) | +0.217, p=0.375 | 유의하지 않고, 검색층에서 차이 없음 |
| 근거 증량 (top-5 → top-11) | 0.000 | 재현 안 됨 |
| answerer 축 열거 프롬프트 | +0.033, p=0.688 | 상한 자체가 작음 |

**살아남은 것**(v1에서, 아직 k=1 근거):
- 리랭커가 단일 최대 지렛대 (complex 0.17 → 0.50)
- 두 층 기권 게이트 — 검색 게이트는 *관련도*, 생성 게이트는 *답변가능성*
- 점수 게이트의 역할은 안전이 아니라 비용 절감
